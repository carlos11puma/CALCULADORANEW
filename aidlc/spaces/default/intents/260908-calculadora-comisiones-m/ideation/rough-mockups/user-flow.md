```
[Login] → [Home: comisión ganada + venta vs presupuesto]
              │
              ▼
   [Ingresar venta de hoy] → [Guardar] → recalcula comisión
              │
              ▼
     [Home actualizado] ──▶ [Historial] (períodos anteriores)
              │
              └──────────▶ [Notificaciones] (proximidad a meta)
```
